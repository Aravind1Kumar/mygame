# 🌀 Super Ceiling Fan Bros

A retro Mario-style 2D platformer starring **Sir Spins-a-Lot**, the heroic ceiling fan on a quest through the living room and attic heights to restore power at the Master Switch!

Playable directly in any web browser with 60 FPS physics, smooth parallax scrolling, procedural canvas animations, and zero-dependency 8-bit synthesized sound effects.

---

## 🎮 Gameplay & Mechanics

- **Roll & Glide**: Steer across platforms with responsive momentum.
- **Flutter Hover**: Hold the jump key while airborne to spin blades at maximum RPM, defying gravity for extended air glide across deep pits!
- **Down-Gust Ground Pound**: Press `Down` in mid-air to blast downward and squash enemies.
- **Turbo RPM Sprint**: Shift into high gear for extra speed and blade power.
- **Power-Ups & Collectibles**:
  - ⚡ **Watts**: Collect 100 Watts to earn an extra life.
  - ⚙️ **Speed Regulator**: Upgrades Sir Spins-a-Lot into **Super Fan Mode** (5 blades, golden shine, and the ability to shatter brick blocks!).
  - ❓ **Mystery Blocks**: Shimmering blocks holding secret Watts and upgrades.
  - 🔌 **Master Power Switch**: Reach the high-voltage lever switch at the end of Level 1-1 to electrify the stage!

## 🕹️ Controls

| Action | Keyboard | Touch / Mobile |
|---|---|---|
| **Move Left / Right** | `A` / `D` or `←` / `→` | On-screen D-Pad `◀` / `▶` |
| **Jump / Flutter Hover** | `Space` / `W` / `↑` (Hold in air to hover) | `HOVER` Button |
| **Down-Gust Ground Pound** | `S` / `↓` | `▼` Button |
| **Turbo Sprint** | `Shift` / `X` | `TURBO` Button |

## 🌐 Play Online with GitHub Pages

To enable live browser play directly from this repository:
1. Go to your repository on GitHub: `https://github.com/Aravind1Kumar/mygame`
2. Click **Settings** ⚙️ > **Pages** (in the left sidebar).
3. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
4. Within a minute, your game will be live at:
   👉 **`https://aravind1kumar.github.io/mygame/`**

## 💻 Local Play

Simply open `index.html` in any web browser, or run a local static server:
```bash
npx serve .
# or
python -m http.server 8080
```
Then visit `http://localhost:8080`.
